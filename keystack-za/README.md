# Keystack ZA

Keystack ZA is a full-stack e-commerce website concept for a South African mechanical keyboard and desk-accessory store. The project uses a simple stack so the code is easy to understand and maintain.

## Technology

- HTML, CSS and JavaScript
- Node.js and Express
- SQLite using better-sqlite3
- bcryptjs for password hashing
- express-session for login sessions

## Main features

- Responsive home page and separate audience pages
- Product catalogue with search and category filtering
- Product detail pages with scroll-reveal effects
- Customer registration and login
- Shopping cart and quantity controls
- Checkout with ZAR totals
- Simulated payment workflow
- Order history, tracking and cancellation
- Simple admin product and order management
- Light and dark theme support

## Run the project

```bash
npm install
npm run seed
npm start
```

Then open http://localhost:3000
